# `mimo-frontend-web-app/` — kiosk front end (container folder)

Holds one application: [`mimo-frontend/`](mimo-frontend/README.md), the touchscreen UI shown on each kiosk. The folder name is a **deployment contract** with Vercel — do not rename or move it.
Everything (setup, screens, API calls, troubleshooting) is documented in [`mimo-frontend/README.md`](mimo-frontend/README.md); the Android shell that displays it is in [`../LENOVO TABLET APP/README.md`](../LENOVO%20TABLET%20APP/README.md).
